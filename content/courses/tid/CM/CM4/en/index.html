Goal Seek

Principle


Classic calculation:

Known budget → Formula → Result

€5,000 → Budget / 650 → 7.69


Goal Seek:

Unknown budget → Formula → Fixed result

? → Budget / 650 → 12


Calc finds the required budget.

Goal Seek


I know:

  • the desired result


I am looking for:

  • the input value

What Goal Seek does



It automatically modifies

a cell


until it reaches the requested result.

Let’s try it in Calc

Cell Content
B2 Budget to find: 5000
B3 Cost per investigation: 650
B4 Number of investigations: =B2/B3

Keep the formula: Calc must adjust the budget.

Open Goal Seek


In Calc: Tools → Goal Seek

  • Formula cell: B4
  • Target value: 12
  • Variable cell: B2


Enter the desired result, not the answer.

Calc found it!


€7,800


7800 / 650 = 12



The formula is unchanged: only the budget cell was adjusted.

No.

The Solver

The principle


Solver automatically searches for

the variable values

that produce

the best result.



while respecting

the constraints.

The Solver receives

🎯 a goal


🔧 variables


🚧 constraints

Example

🎯 Maximize

the number of successful investigations


🔧 Variables

number of investigations in each area


🚧 Constraints

budget ≤ €10,000

time ≤ 120 h

Let’s build the Calc table


Area Investigations (B) Cost (C) Success (D) Hours (E)
Texas 0 500 0.70 8
California 0 650 0.85 10
Nevada 0 800 0.95 12
New York 0 550 0.60 7


Cells B2:B5 are the variables to determine.

Goal Seek or direct calculation?

To get exactly 12 investigations, what must Calc change?

A.   The cell containing the cost per investigation

B.   The cell containing the formula

C.   The cell containing the budget

D.   Every cell in the table

Answer: C. The formula stays the same; Calc adjusts the budget.

Let’s calculate the objective


Expected successes:

=SUMPRODUCT(B2:B5;D2:D5)


Budget used: =SUMPRODUCT(B2:B5;C2:C5)

Hours used: =SUMPRODUCT(B2:B5;E2:E5)


A formula turns our choices into a measurable result.

What should we maximize?

Nevada has a 95% success rate per investigation.

What result should we maximize in our model?

A.   The total cost of investigations

B.   The highest success rate

C.   The total number of hours used

D.   The number of expected successes

Answer: D. For each area, we add investigations × probability of success.

Set up the Solver


In Tools → Solver:

  • Target cell: the expected successes cell
  • Optimize: Maximum
  • Variable cells: B2:B5

But be careful…



We asked Solver to

maximize the number of expected successes.



We did not ask it to distribute teams

An important note



Solver does not decide

what we should look for.



It optimizes

what we ask it to.

Goal Seek

finds one value.



Solver

finds the best solution

according to our objectives and constraints.

Can adding a constraint help?

We keep the same objective, but require at least two investigations in Nevada. What can happen to the best objective value?

A.   It can increase

B.   It cannot increase

C.   It must remain exactly the same

D.   It always becomes zero

Answer: B. An additional constraint reduces the possible solutions, so the maximum cannot increase.

The new result

A model lets us test scenarios.


These are experiments based on assumptions, not automatic decisions.

What we need to understand


The Solver does not know

the best decision.


It only knows

the best solution

to the problem we give it.

In real life


  • organize deliveries
  • allocate resources
  • plan schedules
  • optimize production


In all these cases,

we must choose the objectives and constraints.

A model

is a simplification of reality.


An optimal solution

is only optimal

within this model.
