BLOCK 1

What exactly is a formula?

A formula =


an expression that produces a value

A formula begins with…


= + −


Otherwise, Calc interprets it as text

A formula can use



  • numbers 25, 86, 12
  • cells A1, C3, D8
  • ranges B2:D4
  • functions SUM, AVERAGE
  • operators + − /

The simplest example




=2 + 3

  • connected
  • sometimes dynamic

Why use a function?



Because a function encapsulates a sometimes complex calculation

in a single, simple command.


(which you will not have to perform again yourself)

=MIN()


=MAX()

But there are also more advanced functions

=COUNTIF()

Functions have arguments


A function takes information as input:


=AVERAGE(B2:C3)


Here:

B2:C3 range of cells from B2 to C3

Functions have arguments


Some functions take several arguments:


=VLOOKUP(“Gladiator”; D:D; 3; 0)


The different arguments are separated by ;

Exemple


=VLOOKUP(“Gladiator”; D:D; 3; 0)


  • “Gladiator” what we are looking for
  • D:D where to look
  • 3 which column to return
  • 0 exact match


There is no need to remember everything.

The key is to understand the principle.

A function

is a complicated idea

made easy to use.
